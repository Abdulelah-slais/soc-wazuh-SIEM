# SOC Project – Wazuh SIEM, XDR & SOAR

## Overview

This project involved designing and implementing a Security Operations Center (SOC) environment using Wazuh as the main SIEM platform.

The project combined security monitoring, XDR detection and automated response, intrusion detection, threat intelligence, and SOAR automation to demonstrate a practical SOC workflow for detecting, analyzing, and responding to cybersecurity threats.

---

## SOC Environment

The project environment included:

- Wazuh SIEM
- Kali Linux
- Windows Server 2022
- Bodhi Linux
- Snort IDS
- Shuffle SOAR
- VirusTotal
- AbuseIPDB
- AlienVault OTX

Wazuh served as the central security monitoring platform for collecting, analyzing, and responding to security events generated across the environment.

## XDR Workflow

The XDR component followed the general process:

```text
Attack Simulation
       ↓
Security Event Generation
       ↓
Wazuh Detection
       ↓
Alert Analysis
       ↓
Response Action
       ↓
Response Validation
```

The implementation included attack generation, detection rules, Wazuh dashboard evidence, event identification, response configuration, and validation.

---

## SOAR Workflow

The Shuffle SOAR integration followed this workflow:

```text
SSH Brute-Force Attack
        ↓
Wazuh Detection
        ↓
Custom Wazuh Rule
        ↓
Wazuh Alert
        ↓
Webhook Integration
        ↓
Shuffle SOAR
        ↓
Alert Processing
        ↓
Automated Email Notification
```

A custom Wazuh rule was used to detect repeated SSH authentication failures. The resulting alert was forwarded to Shuffle, where the workflow processed the security event and automatically sent an email notification.
